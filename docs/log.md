# Log

One line per archived change, ADR decision, perf window or owner decision, newest first. **New entries go to `docs/log.d/<YYYY-MM-DD>-<id>.md`, one line per file (BUILD-010); do not edit this file. `cargo xtask log [--since D] [--limit N]` prints both, merged newest first.** Finished milestones are archived by the `housekeeping` skill: `docs/archive/M0-M3/log.md`, `docs/archive/M4/log.md`, `docs/archive/M5/log.md`, `docs/archive/M6/log.md`, `docs/archive/M7/log.md`, `docs/archive/M8/log.md`.
