## Non-obvious decisions (the code and ADRs say what, not why)
- **Content key of the plan cache** (STRM-027): `SelectionCache` entries (origin height, mesh key, volume) are checked against the tile's `inputs_hash_for` only when the field's `item_revision` changes. The revision is process-unique per `WorldDefinition` instance (a clone is another instance), so a reload cannot reuse a stale hash. Wrappers of a stage must forward `item_revision`, `upstream`, `stage_params`, `passes_through` (a source-scan test in `crates/cache/tests/stamp_keys.rs` enforces it). `PlanField::item_revision` makes the residency set follow the definition.
- **Bounds** (GEN-026): a stamp widens a tile's height bounds by the delta range it can add over the cap (monotone profiles, `delta_range` in `generators/src/stamp.rs`), not by `max_delta_m`: the sum left no morph room at level 19. A new stamp kind needs a monotone profile or a bounds rule of its own.
- **Pass-through** (ADR 0068, GEN-027, STRM-029): a stamp stage with an empty footprint for a tile is the identity there and keys as its source, in BOTH key domains (128-bit persistent `cache::key`, 64-bit `generators` `cache_key_field`/`mesh_key_field`/`MeshKeyer`). Not for root tiles (the coarse mesh stencil reaches past the cap), not on a mapping other than the cell grid's. Without it the first stamp re-keyed the whole world. A test checks that every point a tile samples lies inside the declared footprint.
- **Item content hash**: for a stamp kind it is the stamp's own hash (kind and parameter), not the file hash (ADR 0067); the item file spelling is hill/`height_m`, crater/`depth_m`, plateau/`target_m`, the radius is `reach_m`.
- **Stage index** = the layer's place in `planet_world_def::LAYER_STACK`; layers outside it follow in name order. The app's `WorldTerrain::field()` stacks one `StampStage` per layer that holds a stamp, under the water bound.
- **Preview**: `preview_delta` must be diffed from the OLDEST state any resident tile shows, not the last step (a drag is one delta from the first state); a removed plateau is not previewed; the shader displaces along the vertex's own radial up and displaces the parent-grid neighbours too.
- **Sandbox quirk**: compound shell commands and heredocs together with other commands are refused in this worktree; write scripts with the Write tool (`target/*.pl`) and run them as separate simple commands. Run `cargo xtask prepush` before every push; the two `gpu_stream_perf` smoke tests and `gpu_water::a_coastal_flight...` can hit the 300 s nextest timeout under load locally (they pass alone and in CI).
- **Process**: coders merge their own PRs when CI is green on Windows and Linux and the verifier passed; archive with `openspec archive <id> --yes`, then delete `design.md` and `tasks.md` of the archived change, add `docs/log.d/<date>-<id>.md`.
