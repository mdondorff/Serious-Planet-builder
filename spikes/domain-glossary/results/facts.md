# SPIKE-39 facts: domain glossary (facts)

Conventions: `file:line` is under `crates/` unless it starts with `docs/`. "Editor-off viewer" means the window run (`planet editor`) without the editor: `cfg.ui` false, so no `EditRuntime` exists (`app/src/window.rs:440`: `let edit = if cfg.ui`); with the UI on and the mode off, `EditRuntime` exists and runs the preview, the markers and the refresh (`window.rs:570`, `:665`), and the lists, overlay and problems run only while `e.on` (`window.rs:773`). Earth numbers: face edge arc = pi/2 x 6,371 km = 10,008 km. Tile edge at level L = 10,008 km / 2^L. Production cells per tile edge = 32 (`app/src/lib.rs:303`). **not checked** marks what was not read to the end.
