# Spikes

One folder per spike or exploration: `spikes/<name>/results/` holds its report (`results.md`), images, raw numbers and a prototype patch. Spike code itself lives only on its `spike/<name>` branch and is never merged.

- The register (one line per spike, with its status and folder) is `docs/spikes.md`.
- `docs/spikes/` is not a second spike folder: it holds only frozen pictures of SPIKE-03 to 07 that accepted ADRs link to.
- How to open and close a spike: the `spike` skill (`.claude/skills/spike/SKILL.md`).
