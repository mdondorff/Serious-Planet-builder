# SPIKE-106 round 2, addendum: the memo key after its fix (#1355), with a rule flip (the L3 re-run)

Run 2026-11-11 by the spikes lane on the bulldozer's slot. Reported, not gated. Main c5322c4f (`catchment_key` hashes the local clip and the members in `Routing.order`, #1355). Release build, Windows, 8 threads, BelowNormal, margin 200; R3a (seed 15 face 4) and R1 (seed 14 face 1), 1,040,400 cells each. The explorer's and the crusader's prepushes were on the machine: the first memoised solve of R3a took 66 s against 17 s for the same work later, so the times are not a measurement. Probe: `gate_probe keys` on the local branch `spike/gate-remeasure` (spike code, never merged). Raw output: `l5-rule-flip/`.

## Result

**The hole found by L4 is closed.** After the fix every parameter the catchment round reads is in its key, and a memoised solve across a rule flip equals the fresh solve of the same rules in every run.

## 1. The key against each parameter (round 1 from the base; every catchment of more than one cell: 6,387 on R3a, 2,541 on R1)

The inputs are gathered once with the Local rules; each row changes one parameter of `catchment_key`'s `CarveParams` and counts the catchment keys that stay the same.

| Parameter changed | Keys unchanged (R3a, R1) | Reading |
|---|---|---|
| `round_rules.clip_mfd` Local to Off | 0 of 6,387, 0 of 2,541 | in the key (#1355) |
| `k_dt`, `u_over_k`, `epsilon`, `breach_slope`, `breach_max_m` x (1 + 1e-9) | 0, 0 | in the key |
| `breach_height_scale_m` 0 to 100, `sea_level` 0 to 1e-3 | 0, 0 | in the key |
| `keep_pits`, `incise_only` flipped | 0, 0 | in the key |
| `reroute_every` 5 to 4 (the sweeps per round) | 0, 0 | in the key |
| `round_rules.canonical_flood` true to false | all, all | not in the key |
| `steps` 20 to 24 (the number of rounds) | all, all | not in the key: a round does not read it |
| `uplift_taper_m`, `max_area`, `cell_metric` | all, all | not in the key: they act through the taper, `A_d` and distance inputs, which are hashed (the inputs were not regathered in this test) |

- The sweeps of a round matter: 5 against 6 sweeps change the result of 4,583 of 6,387 catchments (R3a) and 2,130 of 2,541 (R1); the key holds them as `reroute_every`.
- `canonical_flood` is not hashed; `solve_rounds_memo` requires the canonical flood, and the test did not check that a non-canonical call is refused.
- Not tested: the `Schedule` field of `CarveParams`, the drivers (`scale`, `up_unit` are hashed), a flip of `reroute_every` through the memoised solve.

## 2. The memoised solve across a rule flip (one `RoundCache`, 4 rounds of 5 sweeps, tile 256, each result against `solve_rounds` of the same rules)

| Call | R3a: carved / answered by the memo, cells differ from fresh | R1: carved / answered, cells differ from fresh |
|---|---|---|
| Local on an empty cache | 21,704 / 5,628, 0 | 8,503 / 1,572, 0 |
| Local again | 0 / 27,332, 0 | 0 / 10,075, 0 |
| Off on the cache of Local | 27,139 / 68, 0 | 9,907 / 9, 0 |
| Off again | 0 / 27,207, 0 | 0 / 9,916, 0 |
| Local after Off | 0 / 27,332, 0 | 0 / 10,075, 0 |

- The fresh solves with Local and with Off differ in 686,553 cells (R3a) and 699,408 (R1) of 1,040,400, so a stale answer across the flip would show.
- Off on the cache of Local carves almost every catchment again (27,139 of 27,207; 9,907 of 9,916): the few answered by the memo (68, 9) are repeats within the solve (the first Local solve answers 5,628 and 1,572 the same way across its rounds), not answers from the other rule.
- The two rules' entries live side by side: Local after Off carves nothing and still equals fresh.

## 3. Caveats

- Two windows, one flip (clip rule Local and Off), 4 rounds, f64 rounds (repeat after GEN-166's f32 rounds). The memoised solve was not run with a changed `reroute_every` or `breach_max_m` on a shared cache; only the keys were compared for those.
- The L3 gaps named in the G-LOCAL verdict of 2026-11-11 (outlet flag and sibling exchange not exercised) were closed earlier, on R3b and R1 (`remeasure/local2_*`); R3a still moves 0 for both.
- Reported, not gated.
