## Context
- Owner (2026-10-19): a region's mask clips a chosen layer's edits, inside or outside, like a layer mask; the outline is a closed points list; surface types are a data table.
- `line-items` gave the item the points, `group`, `part` and `mask_layer`; the footprint returns an item to a tile when its reach (anchor, `reach_m`) meets the tile's cap (WDEF-007), per layer, and the tile's key chain covers what it read (WDEF-008, STRM-027, CON-07).

## Decisions
1. **Table.** `SURFACE_TYPES` in `world-def::region`: nine `{name, tint}` rows in the owner's order; a region stores the index as the whole-number parameter `surface_type`. A table of rows is data; a later entry is a row (the debug overlay reads the tint).
2. **Stamp kind.** `StampKind::Region = 6`, parameters `[surface_type, mask_mode, 0]`, the points in the stamp; no height of its own (`stamp_delta` 0, `delta_range` 0). Its content hash is the stamp hash (kind, parameters, points).
3. **Layer.** A mode-2 region is filed in the layer `mask_layer` (the `ItemSpec` layer), so the footprint of a tile of that layer returns it. A mode-0 region keeps the item's own layer and changes no output (it is a label for the overlay).
4. **Put refusals** (WDEF-012): 3 to 64 points, unit directions, the first the anchor, no two consecutive equal (last and first included), non-self-crossing on the gnomonic projection at the anchor, every point within `reach_m` of the anchor, `surface_type` a whole number below 9, `mask_mode` 0 or 2 (1 refused with the reason of decision 7), `mask_layer` required for 2 and refused for 0.
5. **Inside test.** The even-odd rule on the gnomonic projection onto the tangent plane at the anchor (f64; a point behind the plane is outside); the boundary counts inside to 1e-12 of the projection's unit (about 6 um). Self-intersection: a segment pair test of non-neighbour edges.
6. **Mask.** In `apply_stamps`, a mode-2 region in the footprint that contains the point returns the base unchanged (all deltas of the layer cut, whatever the order); the cut is per point (hard edge). The delta range over a cap is the unmasked one (a mask only removes deltas, so it still encloses them). The stage version goes to 3.
7. **Mode 1 (clip outside) is refused. What it takes, for the owner:** everything outside the polygon, anywhere on the body, is cut, so every tile of the layer must read the region: the tile's read set (footprint kind 3 and summary kind 4 entries, ADR 0066) must contain a "global items of the layer" entry. That means (a) a per-layer set of global items in the definition (an `ItemRec` flag; the item is still filed in its cell for lookups), (b) `footprint_items` and the cap form returning them for every tile and cap of the layer, (c) a new read-record kind (5, global items of a layer: their item hashes) in `GenContext`, in the tile's read set and in the summaries' root hash, so the key of every tile of the layer changes when a mode-1 region is added, edited or removed (CON-07; this is the "full refresh" cost: every resident tile of the layer is refreshed once), (d) the bound: unchanged (a mask only removes deltas), (e) a limit of one mode-1 region per layer and body (two outside-clips would mean the intersection of two polygons; the second is refused), (f) tests of the key chain (a far tile's key changes with the region; two layers independent), and an ADR note on the new read kind (it touches ADR 0066's chain). Cost: a day of work plus the refresh of the layer on every edit of the region. Alternative without the new read kind: the editor expresses "clip outside" as clip inside several regions that tile the complement within the area of interest (the owner's regions are small): no engine work, but a lot of polygons.

## Risks
- A polygon with a point at the horizon of the tangent plane (over 40 km) cannot be projected: refused by the reach rule.
- A mode-2 region cuts every delta of its layer in its area, including a plateau's flattening: intended (a layer mask).
- Stage version 3 re-keys stamped tiles (no output changes without regions).
