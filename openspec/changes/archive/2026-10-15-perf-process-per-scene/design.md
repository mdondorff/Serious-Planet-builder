## Decisions

- **Where the orchestration lives.** `planet-perf::session` (GPU-free, std only) holds `ChildRunner`, `run_scenes`, `summary` and the `SCENE-MEMORY` line format; `xtask` depends on `planet-perf` for it and provides the spawn (`cargo run ...` with stdout teed and kept). The tier A tests use a fake runner.
- **Per-scene RAM source.** The child already reads its own peak working set after its case (`PeakWorkingSet64`/`VmHWM`); with one scene per process that is the scene's own. The child prints it, with the VRAM and slot figures, in one `SCENE-MEMORY` line; the parent parses the line from the child's stdout (also works in smoke, where no log is written). A missing line is reported as such, not invented.
- **Gate.** Per child: the gate samples the machine for 10 s and needs the adapter, so it runs where the adapter is. Cost: six gates per `all` session. Benefit: each scene is gated on the machine as it is then (a scene that heats the machine cannot hide behind a gate passed earlier). `--machine-ready` is passed to every child.
- **Slots.** `pool_slots` is the main pool's ceiling in slots (`PoolConfig::main_slots`, what the residency manager counts its capacity in); `share_slots` is `share_bytes / slot_bytes` (what the share would hold if all of it were slots). The verdict is OK if the pool fits the share's slots; the most slots resident in any frame is shown beside.
- **CPU clock.** `Win32_PerfFormattedData_Counters_ProcessorInformation`/`_Total` (`PercentProcessorPerformance`, `ProcessorFrequency`) through one PowerShell call, about 1.5 s, taken at the start and end of the case outside the frame loop. The counter path `\Processor Information(...)` is localised and fails on a German Windows; the WMI class name is not. `Win32_Processor.CurrentClockSpeed` reports the base clock, not the effective one, so it is not used. The power plan is parsed from `powercfg /getactivescheme` by the shape of the GUID. The values are logged in the counts and are excluded from the baseline comparison (`RECORDED_ONLY_COUNTS`); old logs without them compare as before.
