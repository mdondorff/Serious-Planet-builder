## Why

M3 exit criterion and risk register ("stale cache from incomplete cache keys"): `cache-verify` regenerates stored tiles from scratch and compares them with the cache, so a key that leaves an input out is found by a command, not by a wrong picture. It needs a payload format for height tiles and a way to fill a store.

## What Changes

- `planet_cache::codec`: the height tile payload (ADR 0019): codec version, resolution, raw length, an LZ4 block of the heights shuffled by byte index. Bit-exact for every `f32` pattern; hostile headers refused before any allocation. `lz4_flex` `=0.14.0` (`std`, `safe-encode`, `safe-decode`: no unsafe; MIT; `cargo deny` clean).
- `planet_cache::tiles`: `World` (the single planet of a definition: field through the reference generator, radius, store parameters, node set id), `region_tiles`, `build_tiles` (reuses what is stored under the current key), `verify_store` (sample, regenerate, compare decoded heights; stale vs mismatch vs unreadable vs other kind) and `VerifyReport`. `TileStore::sample_records` and `Stored`.
- `generators`: `generate_tile_field` (a tile of any height field; `generate_tile` delegates to it, output unchanged).
- CLI: `planet generate --cache-dir DIR --region FACE,LEVEL [--res N] [--seed N | --world file.toml]` and `planet generate --verify-cache DIR [--sample N] [--seed N | --world file.toml]` (the mismatch lines name tile, pack, offset, key and first differing sample and the command fails); `cargo xtask cache-verify <dir> [...]` runs it in release mode.
- Added: STRM-009 (payload codec). Modified: STRM-004 (now active). Tests: fourteen in `cache/tests/tiles.rs` (codec round trip, every byte value at every position, hand-built layout, hostile and too-long/too-short blocks, a validating encoder, build and reuse, build refusals, compared-nothing and explained/unexplained stale, the missing-input scenario with a forged tile, a generator that reads a node behind the context's back, an item edit rebuilding exactly the affected tiles, metadata and damage reporting, even sampling), three in the app (plus option rules) and one in xtask.
- Not here: compaction and the size cap, mesh verification (only height tiles are regenerated; other kinds are counted), wiring the store into the streamer, a `--world` for `editor`/`test-render`.
- Review fixes (verifier, spec-guardian, numerics-reviewer): a run that compares nothing no longer passes (`--allow-stale`), stale entries are split into explained and unexplained, record metadata (generator version, hash version, node set id) is checked, every entry is decoded before it is classified, records the pack scan skipped are reported by verify with pack, offset and key (found by the verifier on the real command), the encoder refuses what the decoder would refuse, `region_tiles` and `build_tiles` refuse out-of-range inputs, the sampling arithmetic cannot overflow, `World::from_generator` takes any generator (so a leaky generator and a cell-reading generator can be tested through the real pipeline), the CLI refuses ignored or misplaced options and a missing directory.
- Not here, recorded: multi-body (only body 0 is stored and verified; other bodies of a definition are ignored), authored layers beyond what a cell-reading generator brings, compaction, mesh verification, streamer wiring. A same-definition verify finds nondeterminism, damage and wrongly written records, and finds an input missing from a key only when that input's value differs between building and verifying (learning 2026-10-12).
- From the architect's review of ADR 0023/0024 (applied here): `res` is cells (intervals) per edge everywhere (the unit of `TileData::res` and of the mesh's `cells`; a plane has `(res + 1)^2` samples), the docs now say so, `mesh_key_inputs` exposes the mesh key's source, and a test pins that a stored height tile's key is the mesh key's source key (no pinned value changed); `read_index` now requires entries strictly increasing in (sort key, key), so a foreign index with two entries for one record is rebuilt (a hand-made duplicate index is tested).
