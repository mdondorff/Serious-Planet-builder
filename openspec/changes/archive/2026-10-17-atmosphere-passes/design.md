## Design

The WGSL mirrors `planet_frame::look::atmosphere` (ADR 0050 points 1-3). The composite is a fullscreen pass reading a scene target (the terrain draws there when the plan has an atmosphere), the depth the terrain kept, the sky-view table, the aerial-perspective volume and the static tables; it writes the lit path HDR target, so exposure and tone map are unchanged. Terrain atmosphere pipelines add group 3 (uniform block and the two tables) in the vertex and compact formats alike; the compact pipeline keeps groups 1 and 2 and the vertex pipeline leaves them null, so one bind group set once per pass stays bound across pipeline switches. Tables are generated and uploaded by `enable_atmosphere` and again only when a plan names another body.

Bound tests use probes: the shader functions run on given inputs (sky texel, aerial texel, orbit march by cosines, lighting) next to the reference on f32-rounded inputs. The orbit rays are given by their cosines (the rounded dot products are the input, not the march); the ground limb has a threefold allowance within 2e-6 rad. The aerial-perspective rays end at the depth: the reference sphere cuts nothing, so terrain below it is hazed.
