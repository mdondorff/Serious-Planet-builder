## Decisions

- **R is the existing position-only selection plus its ancestors.** `select_nodes*` already ignores the view direction (no frustum), applies the horizon cut and the per-node height bounds. `residency_set*` wraps it, adds every ancestor and gives each tile a distance (leaf: its own; ancestor: nearest descendant leaf). Entries are in ascending tile id order (deterministic, CON-14).
- **One queue key, three classes.** `(class, rank, priority key, tile)`. Class 0 keeps the old key (`priority - depth * 1e12` through the wanted tile's ancestors) so the dive and the `--stream` order do not change. Class 1 ranks by level (coarse first), then the caller's priority (distance; the caller may put in-view first), class 2 the same. A tile in several classes takes the highest.
- **Cancellation set = D, R and the prefetch set with all their ancestors.** The frustum is not an input of that set; a rotation changes D, which is a subset of R, so once R is resident a rotation changes nothing (tier A over many yaws). Queued prefetch requests that left the prefetch set are counted separately (`cancelled_prefetch`).
- **Prefetch rules.** Dispatched only when no class 0 or 1 request is queued, and only while `resident + in_flight < capacity` (free capacity). Prefetch tiles are never touched as "used", R and D tiles are touched each frame, so eviction (unchanged: LRU beyond capacity, tiles used this frame stay) takes prefetch tiles first and a prefetch result never evicts R or D. The pooled-slot manager and the share arrive in the next change.
- **Stage boundary.** `TileSource::load_staged(tile, &CancelToken)` defaults to `load`; a staged source polls the token between stages and returns `Ok(None)`. The streamer drops the result of a job whose token is set when it completes (the persistent cache already holds it; nothing is made resident). If a cancelled in-flight tile is needed again before it completes, the token is cleared.
- **Determinism.** The queue is a `BTreeMap` over a total key; the plan is a pure function of the wants, the resident set and the failure times. The thread-count test lets every dispatched job complete before the next frame.
- **Predicted position** is `position + velocity * look_ahead` with the look-ahead capped; yaw and pitch are not parameters.
