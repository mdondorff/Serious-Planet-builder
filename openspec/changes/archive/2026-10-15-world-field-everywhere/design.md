## Decisions

- **Where the eroded field's bake comes from.** An in-memory bake of `--global-res` cells per face edge, the mechanism #110 built for `--world`. The default is the option's existing default (256), the cap 1024 (about 100 MB). The store is not used: a perf window must not depend on a directory on the machine, and the counts then name the bake they were made over. A run over the 16384 store stays an ad hoc tool (`plan_ablation`, `store_blocks`, `generate --plan-check`).
- **Which runs mean which field.** `--world FILE` names the definition and so the field. Without it, a view, `--stream`, `--bundle` and `--flight` are the seed-only world with `cpu-ref-height-v2` named explicitly (goldens, plan snapshots and bundles keep their keys); `--perf` and `--perf-smoke` are the default world of `--seed` (the eroded field), because the perf scene measures what a user gets. `--global-res` without `--world` is accepted only by the perf scene. `--seed` with `--world` is still refused.
- **Bundles.** A run that named a world records it whole in the bundle: `height_field <id>`, `global_res <n>` and `world_toml <canonical TOML, escaped on one line>`, with `definition_hash` the definition's hash. The bake is a pure function of the definition and `global_res` (CON-14), so these three lines reproduce the field exactly. Format version 2; version 1 bundles are the seed-only reference field and still replay, a version 1 header with a world section is refused, and a half-recorded world is refused. Replay refuses, before replanning, a world that does not hash to the recorded hash, a field id that the recorded world no longer resolves to, and a radius that differs from the request's. A seed-only run writes no world section (format 2, field implied by the seed).
- **`--repro` with `--world`** is refused: the bundle is the single source of what is replayed.
- **Streaming.** `MeshSource` owns an `Arc<WorldTerrain>` and builds the field in `load` (the eroded field's constructor reads the definition and borrows the bake). `WorldTerrain` therefore holds a `Send` lattice source.
- **Perf scene.** The bake runs before the readiness gate so its CPU load is not measured as the machine's. The LOD `max_height_m` is the larger of the default and the field's bound, as in `render_terrain`. The log records the field in `protocol.field` (and the scene prints it).
- **Regression report.** `comparison_lines` skips a comparison when the baseline's `protocol.field` differs from the session's (a log without the field counts as differing from one with it) and says so; the session replaces the baseline when valid. No count or median is compared across the field change.
- **TEST-011 pins.** The default world's pins live beside the world code (they need `WorldTerrain`, which the GPU-free frame crate cannot have) and name their bake. The reference pins stay in the frame crate.
